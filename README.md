# Analisis_Siniestralidad_Vial_Carreteras_Peru
El objetivo principal es realizar la carga, limpieza, preprocesamiento y análisis exploratorio inicial (EDA) de un conjunto de datos sobre accidentes de tránsito en carreteras de Perú durante los años 2020 y 2021, registrado por la SUTRAN (Superintendencia de Transporte Terrestre de Personas, Carga y Mercancías).
